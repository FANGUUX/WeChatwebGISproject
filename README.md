# 南京景点推荐微信小程序

一个带有GIS功能的微信小程序，提供南京热门景点推荐和路线规划功能。

## 功能特性

### 🗺️ 地图展示
- 基于微信地图组件的交互式地图
- 显示南京主要景点位置标记
- 支持地图缩放、平移、旋转操作
- 实时定位功能

### 📍 景点推荐
- 收录南京10+热门景点
- 包含中山陵、夫子庙、玄武湖、明孝陵等知名景点
- 景点分类筛选（历史文化、自然风光、博物馆等）
- 景点搜索功能
- 按评分、距离排序

### 🧭 路线规划
- 支持步行、驾车、公交、骑行四种出行方式
- 显示预估距离和时间
- 路线详情展示
- 一键调用微信导航

### 📱 景点详情
- 景点详细介绍
- 开放时间和门票信息
- 景点位置地图
- 附近景点推荐
- 收藏功能
- 分享功能

## 使用方法

### 开发环境
1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本项目到本地
3. 在微信开发者工具中导入项目
4. 在 `project.config.json` 中替换 `appid` 为您的小程序AppID
5. 编译并预览

### 正式发布
1. 在微信公众平台注册小程序
2. 配置相关权限（地理位置等）
3. 上传代码并提交审核
4. 审核通过后发布

## 技术特点

- **纯微信小程序原生开发**：无需额外框架
- **GIS地图集成**：使用微信内置地图组件
- **响应式设计**：适配不同屏幕尺寸
- **性能优化**：合理使用 setData，避免频繁更新

## 权限说明

本小程序需要以下权限：
- `scope.userLocation`：获取用户位置，用于定位和路线规划

## 注意事项

1. 路线规划功能在真机上效果更好
2. 首次使用需授权位置权限
3. 景点图片需替换为实际图片资源
4. 实际项目中建议对接高德或腾讯地图API获取精确路线
